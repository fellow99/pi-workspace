> **文档编号**：`docs/能力对照清单.md`
> **生成日期**：2026-10-29
> **核对方式**：先依据各工程文档（README / 工程规划 / 能力清单 / 真机验证记录）与上游 `pi-web/docs/agents/*.md` 建表，再**逐项对照各应用当前源代码**核实；凡源码与文档不符，已更新本表状态并登记到 §5「不一致项（待回写）」，明细另见 [`文档实现不一致项.md`](./文档实现不一致项.md)。
> **状态口径**：✅ 源码在位且（按各工程记录）真机实测通过　🔧 源码在位（已实现/已装配），**尚无真机实测记录**　⚠️ 受限/部分可用　❌ 不可用或明确不做　⬜ 未实现/未实测　➖ 不适用
>
> **重要说明（源码核实后的总体结论）**：
> - 各工程文档的**撰写时点不一**：`pi-desktop-hos` 与 `pi-desktop-ark` 的能力清单/复刻评估停留在 **204 Git 插件落地之前**；`pi-desktop-ark` 的 README/工程规划仍写「骨架」；`pi-desktop-android` 的 README 是**占位文件**。因此文档口径普遍**落后于源码现状**。
> - 本表「源码核实状态」列以**当前磁盘源码**为准；「文档口径」列保留各文档的原始说法，两者的差异即 §5 的不一致项。
